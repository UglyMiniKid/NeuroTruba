# Industrial Safety AI: Система прогнозирования аварийных ситуаций

> [!IMPORTANT]
> **Учебный проект**
> Данный проект разработан в образовательных целях и демонстрирует применение нейросетевых алгоритмов для мониторинга промышленной безопасности на опасных производственных объектах (на примере цехов производства Азот).

## 🎯 Описание проекта

Цель работы — создание системы **предиктивной аналитики**. Программа анализирует связку параметров температуры и давления, выявляя скрытые зависимости и аномальные тренды **до того**, как они достигнут критических значений и приведут к срабатыванию систем защиты.

## ✨ Основные возможности

- 📂 **Импорт и обработка данных** из таблиц Microsoft Excel (`.xlsx`)
- 📈 **Интеллектуальный анализ** динамики изменения физических показателей
- ⚠️ **Классификация** текущего состояния оборудования по уровням риска

## 📊 Описание входных данных

Система работает с историческими данными телеметрии:

| Параметр | Описание |
| :--- | :--- |
| 🌡️ **Температура** | Текущие показатели теплового режима процесса |
| 💨 **Давление** | Показатели давления в системе |

## 🛠️ Технологический стек

- **Python 3.14**
- **Pandas** — для работы с таблицами
- **Scikit-learn** — для реализации нейросетевой модели
